تنظیمات

برای این قابلیت، افزونهٔ همراه را نیز در Chrome یا Edge نصب کنید. تنظیم این بخش فقط ترجیح شما را ثبت می‌کند؛ فعال‌سازی و خاموش‌کردن محافظ وب از داخل افزونه انجام می‌شود.

در صفحهٔ افزونه‌های مرورگر، Developer mode را روشن کنید و پوشهٔ browser-extension را با Load unpacked انتخاب کنید.

بررسی فقط هنگام باز کردن برنامه انجام می‌شود. این برنامه رسمی Anthropic نیست.
